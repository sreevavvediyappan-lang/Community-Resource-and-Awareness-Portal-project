# Community Profile
## OVERVIEW
<p>The Community Profile feature allows users to view important information about a particular community in one place. It provides basic details, available resources, community needs, and awareness information.</p>
<hr>


##  Description
<p>Create a community profile page to display important information about a community</P>
<hr>


## Features
- Community name and description
- Location
- Available resources
-  Awareness information
- Community needs
<hr>


## Acceptance Criteria
  1. Profile page is created
2.Community details are displayed
3.Resources and awareness information are shown
4.Page is simple and user-friendly
